# UNITED AFRICAN ASCENT LEAGUE (UAAL)

A premium sports league app experience inspired by the Premier League and La Liga, rebuilt for Africa's elite competition with modern analytics, privacy-first data handling, and a premium dark gold visual design.

## Features
- Live match center and fixtures
- League standings and top scorers
- Player profile, transfers, and stats
- Club analytics and reports
- Media and highlights hub
- Privacy-first architecture for user data
- Responsive, mobile-first design

## Tech Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- Node.js backend ready structure

## Run locally
```bash
cd frontend
npm install
npm run dev
```

Then open:
```bash
http://localhost:3000
```
